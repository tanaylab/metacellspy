compute_modules 

Group genes into modules of each block. See the Julia documentation for details.

metacellspy.compute_modules. compute_blocks_modules ( daf : DafWriter , * , max_clusters : int | None = None , min_member_correlation : float | None = None , min_orphan_correlation : float | None = None , min_strong_UMIs : int | None = None , min_strong_cells : int | None = None , kmeans_rounds : int | None = None , module_status : bool | None = None , rng : int = 0 , overwrite : bool | None = None ) → None [source] 

Compute and set vector_of_anchor_per_module , matrix_of_is_found_per_module_per_block , matrix_of_module_per_gene_per_block , and (if module_status is specified), matrix_of_module_status_per_gene_per_block . See the Julia documentation for details.
