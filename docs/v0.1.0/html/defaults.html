defaults 

The default values used by the computations. See the Julia documentation for details.

These are a snapshot taken when this module is imported, and are informational only. The wrappers never pass them on, so Julia always applies whatever value is bound at the time of the call.

metacellspy.defaults. GENE_FRACTION_REGULARIZATION_FOR_CELLS : float = 0.0001 

The regularization factor added to gene fractions of cells.

metacellspy.defaults. GENE_FRACTION_REGULARIZATION_FOR_METACELLS : float = 1e-05 

The regularization factor added to gene fractions of metacells.

metacellspy.defaults. MIN_SIGNIFICANT_GENE_UMIS : int = 40 

The minimal number of UMIs of a gene for its measurement to be considered significant.
