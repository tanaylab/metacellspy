class metacellspy.pipeline. SharpeningRound ( jl_obj : Any ) [source] 

One round of the sharpening_rounds() . The index is the number of the round, starting at 1. The previous_daf is the metacells of the round before this one. The metacells_prefix and the blocks_prefix are this round’s prefixes. The rest are as given to sharpening_rounds() . See the Julia documentation for details.

Run this round, creating a repository with the name in the round’s directory , and return it. Any of the round’s parameters can be overridden for this round only. See the Julia documentation for details.
