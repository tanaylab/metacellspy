API 

Metacell analysis, wrapping the Metacells.jl Julia package. See its documentation for what each computation does.

The API is the same as the Julia one, with the following adaptations:

  • The Julia ! suffix, marking a computation which modifies its data, is dropped from the name.

  • Every optional parameter defaults to None , meaning “use whatever the Julia default is”. The Julia defaults are therefore never restated here, which matters because some of them are computed from the values of the other parameters.

  • The rng parameter is an int seed rather than a Julia random number generator. The default 0 means “use Julia’s default generator”, that is, do not force reproducible results.

  • The computations which return a data frame return a pandas.DataFrame .

  • The contracts, which declare what data each computation reads and writes, are not exposed, as they are only usable from Julia. See the contracts documentation for the vocabulary of what lives in a repository.

This is unrelated to the metacells Python package, which is a separate and independent implementation.
